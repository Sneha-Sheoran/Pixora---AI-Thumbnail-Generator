# Pixora

### AI-Powered Thumbnail Generator

**Pixora** is an AI-powered thumbnail generation platform that transforms a simple title or topic into a visually relevant, high-quality thumbnail. Instead of generating generic images, Pixora uses the user's content as the primary context and allows further customization through styles, colors, aspect ratios, and additional prompts.

> **Turn an idea into a thumbnail — intelligently.**

---

## ✨ Features

* 🧠 **Title-Aware Generation** — Generates visuals based on the actual meaning of the title.
* ✍️ **Additional Prompts** — Add specific objects, moods, lighting, environments, or creative directions.
* 🎨 **Multiple Thumbnail Styles** — Choose from different visual treatments such as Bold & Graphic, Cinematic, Minimal, Realistic, and more.
* 🌈 **Custom Color Schemes** — Control the overall visual color direction.
* 📐 **Multiple Aspect Ratios** — Supports **16:9, 1:1, and 9:16** formats.
* 🖼️ **AI-Generated Visuals** — Creates high-quality visuals optimized for thumbnail usage.
* 🔤 **Clean Text Overlay** — Keeps thumbnail text separate from AI-generated imagery for better typography.
* 👁️ **Live Preview** — Preview the generated thumbnail directly inside the application.
* 📱 **Responsive UI** — Designed to work across different screen sizes.

---

## 🚀 How It Works

```text
User enters Title / Topic
          ↓
Semantic Understanding
          ↓
Visual Concept Generation
          ↓
Additional Prompt
          ↓
Style + Color + Aspect Ratio
          ↓
AI Image Generation
          ↓
Thumbnail Preview
```

The **Title** remains the primary source of meaning, while the **Additional Prompt** provides optional creative control.

For example:

**Title:**
`10 Tips for Better Sleep`

**Additional Prompt:**
`Peaceful bedroom, moonlight through the window, warm bedside lighting`

Pixora combines both to create a sleep-focused thumbnail instead of an unrelated generic image.

## 🧠 AI Generation Approach

Pixora follows a **content-first generation strategy**.

Instead of directly passing the user's title to an image model, the application builds a structured visual prompt:

```text
Title
  ↓
Topic Understanding
  ↓
Visual Subjects
  ↓
Scene & Environment
  ↓
Additional Creative Direction
  ↓
Style & Color
  ↓
Composition
  ↓
AI Image Generation
```

This helps prevent irrelevant outputs and makes the generated image more closely aligned with the user's content.
